# android — the on-device app

Two things live here, and only one needs the Android SDK.

```
platforms/android/
├── core/   pure Kotlin/JVM: detectors, fusion, state machine, fingerprinting,
│           the Sharp AQUOS client with VOLM ducking, the engine — builds and
│           tests anywhere with a JDK 17
└── app/    the thin Android shell: microphone foreground service, settings,
            notification actions, Quick Settings tile — needs the SDK
```

Design: `docs/android-app-design.md`. Decision record: ADR 0007.

## What it does

The phone's microphone hears the TV; the same detector/fusion/state-machine
logic as the Python core (ported constant-for-constant) decides when a
commercial is playing; the phone tells the **Sharp LC-46LE830U** to **duck**
to a low volume over Wi-Fi (`VOLM`), and restores it when the break ends. No
Pi, no capture stick, no relay, no IR. Ducking rather than muting is the whole
trick: the mic keeps hearing the set, so the app knows when the ad ends.

## Build

```
cd platforms/android
./gradlew :core:test                       # anywhere: 21 tests, two of them conformance
./gradlew :app:assembleDebug               # needs the Android SDK (Android Studio / CI)
# → app/build/outputs/apk/debug/app-debug.apk
```

Without the SDK, `ADHUSH_CORE_ONLY=1 ./gradlew :core:test` builds and tests the
core alone. CI (`.github/workflows/android.yml`) builds the APK on every push
that touches this tree and attaches it to each release.

## Install (sideload)

The APK is **debug-signed** — fine for your own phone, not for a store. Copy it
over, allow installs from your file manager, open it. Then:

1. On the TV: MENU → Initial Setup → Internet Setup → Network Setup →
   **IP Control Setup** → Enable; note the port and any login ID / password.
2. In the app: TV address and port, login if set, **Save**, then **Test TV**.
   The test answers the design's open question on your firmware — whether
   `VOLM?` returns the current volume — and does a 1.5 s mute and a 1.5 s duck
   so you can hear both work.
3. **Start**. Grant the microphone permission. The notification carries
   **Not an ad**, **Is an ad**, **Stop**; the **Not an ad** Quick Settings tile
   is the fastest correction.

Battery optimisation exemption is worth granting (Settings → Apps → AdHush →
Battery → Unrestricted) or Android may pause the service overnight.

## What is verified, and what is not

- **Core**: 21 JUnit tests pass, including two **conformance** tests against
  fixtures generated by the Python core (`tools/gen_conformance.py`): every
  block's dBFS, spectral flatness, chroma signature and loudness confidence
  match, with a worst short-term LUFS delta of 5e-10, and a scripted
  fusion / state-machine replay matches Python tick for tick. The Sharp client
  is tested against a fake set over a real loopback socket, including the
  login handshake, refusal, ducking, restore-after-crash and the
  remote-wins rule. An end-to-end engine test mutes an ad pod after the dwell,
  unmutes when it ends, and learns it.
- **App**: compiled and packaged **only in CI** — this tree was written where
  the Android SDK cannot be downloaded. It has not run on a phone yet. The
  microphone path (`UNPROCESSED` vs `CAMCORDER`), the foreground-service
  lifecycle and the notification actions are the first things to try.
- **Thresholds that need your room**: the mic silence detector's
  `quietMarginDb` (4 dB) and the fingerprint verify agreement (0.7) are
  starting guesses; see the design's testing section.

## Thin client (still supported)

The installable web app served by a Pi or PC core (`docs/release.md`) remains
the right choice when a passthrough box is in play or the TV has no network
control.
